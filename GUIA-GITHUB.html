De la carpeta a una liga pública

El proyecto ya está preparado para GitHub Pages. No necesita instalar paquetes ni ejecutar una compilación.

Opción sencilla: desde el navegador

  1. Descomprime el ZIP y abre la carpeta heroinas-olvidadas. Abre index.html para revisar la página.
  2. Inicia sesión en GitHub con la cuenta de quien entregará la tarea. Usa New repository, nombre heroinas-olvidadas, visibilidad Public y Create repository. Usa un nombre distinto si ya existe.
  3. En el repositorio, abre uploading an existing file (o Add file → Upload files). Arrastra el contenido de la carpeta, incluida la subcarpeta assets. No subas el ZIP ni una carpeta adicional que envuelva todo. index.html debe quedar directamente en la raíz.
  4. Escribe un mensaje de commit y pulsa Commit changes. Si no se incluye .gitignore por ser un archivo oculto, créalo con Add file → Create new file y copia el que viene en el paquete.
  5. Abre Settings → Pages. En Build and deployment → Source, elige Deploy from a branch. Selecciona main y /(root); pulsa Save.
  6. Espera a que termine la publicación. Recarga Pages y copia la dirección que aparezca como Your site is live at. Si falla, revisa la pestaña Actions y que index.html esté en la raíz.
  7. Abre la liga en una ventana de incógnito y en tu celular. Revisa las diez imágenes, las cuatro secciones, el quiz, la ampliación y el laboratorio.

Opción con terminal

Abre una terminal dentro de la carpeta del proyecto. Crea primero un repositorio vacío en GitHub. Los datos de identidad se configuran solo para este proyecto.

git init
git config user.name "Tu Nombre"
git config user.email "tu-correo@example.com"
git status
git add .
git commit -m "Completar historieta interactiva"
git branch -M main
git remote add origin https://github.com/TU-USUARIO/heroinas-olvidadas.git
git remote -v
git push -u origin main

GitHub solicita autenticación mediante navegador, GitHub CLI o un token según tu configuración; la contraseña de la cuenta no sirve como contraseña Git por HTTPS. No pongas contraseñas ni tokens dentro de los archivos. Después activa Pages como se indica arriba.
